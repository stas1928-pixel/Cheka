# External sources consulted

Record every external URL used for a decision, with the date checked.

| Date | Source | What we learned |
|---|---|---|
| 2026-09-15 | https://cdnjs.cloudflare.com/ajax/libs/chess.js/1.0.0/chess.min.js | **404.** The prototype's script tag pointed at a file that does not exist. chess.js 1.x is shipped only as ESM/CJS (`dist/esm/chess.js`), no browser global. |
| 2026-09-15 | https://cdn.jsdelivr.net/npm/chess.js@1.0.0/dist/esm/chess.js | Vendored as `vendor/chess.js` (72 KB, BSD-2-Clause, licence alongside). `move()` **throws** on an illegal move in 1.x, it does not return null. |
| 2026-09-15 | https://explorer.lichess.ovh/masters and https://explorer.lichess.org/masters | Both answer **HTTP 401 Authorization Required** to anonymous requests, from two unrelated networks. CORS headers allow `Authorization`. Conclusion: the masters explorer now needs a Lichess personal API token sent as `Authorization: Bearer <token>`. Create one at https://lichess.org/account/oauth/token (no scopes needed). |
| 2026-09-15 | https://raw.githubusercontent.com/lichess-org/api/master/doc/specs/lichess-api.yaml | Explorer params: `fen`, `play` (comma-separated **UCI** moves, not SAN), `since`, `until`, `moves` (how many to return), `topGames`. Response: `white`, `draws`, `black`, `moves[] {uci, san, white, draws, black, averageRating}`, `opening {eco, name}`. |
| 2026-09-15 | `explorer.lichess.ovh/masters` with a personal token | Token confirmed working. Scotch Gambit main line taken as the top master move at every ply: 1.e4 e5 2.Nf3 Nc6 3.d4 exd4 4.Bc4 Nf6 5.e5 d5 6.Bb5 Ne4 7.Nxd4 Bd7 8.Bxc6 bxc6 9.O-O Bc5 10.f3 Ng5 (Max Lange Attack, 693-2843 games per node). After 4.Bc4: Nf6 67%, Bc5 23%. |
| 2026-09-15 | `explorer.lichess.ovh/lichess?ratings=1400,1600,1800&speeds=blitz,rapid` | Amateur database, used to pick every branch reply because it matches the opponents actually faced. Key figures quoted in the notes in `js/repertoire.js`, e.g. 4.Bb5+ c6 scores 63% for Black; 5.Ng5 Be7 scores 59%; 3...Bc5 c3 scores 58% for White. |
| 2026-09-15 | Chess.com scan of `stas1928`, last 6 months (421 standard games) | 56 Scotch games and 42 Elephant games. Showed the repertoire's 4.Nxd4 was never played (4.Bc4 24×), which is why the main line was rewritten. All frequent opponent deviations were turned into branches. |
| 2026-09-15 | https://github.com/nmrugg/stockfish.js (README) | Stockfish.js 18 comes in five builds. **Lite single-threaded** is the README's own recommendation: ≈7 MB, no COOP/COEP headers, far stronger than any human. Built files are **GitHub release assets**, not in the repo tree, and jsDelivr refuses the npm package (>150 MB). Vendored from `releases/download/v18.0.0/stockfish-18-lite-single.{js,wasm}` into `vendor/stockfish/`. GPL-3 (`Copying.txt` beside it). |
| 2026-09-15 | https://raw.githubusercontent.com/nmrugg/stockfish.js/master/examples/loadEngine.js | Protocol: `new Worker(path)`, `postMessage('uci')`, answers via `onmessage` as strings that may hold several `\n`-separated lines. Wait for `uciok`, `readyok`, `bestmove`. The `.js` finds its `.wasm` next to itself via the Worker URL. |
| 2026-09-15 | https://www.chess.com/news/view/published-data-api | `GET https://api.chess.com/pub/player/{username}/games/archives` lists month URLs; `.../games/{YYYY}/{MM}` returns `games[]` with `pgn`, `white.username`, `black.username`, `white.result`, `time_class`, `rules`, `end_time`. No auth. Serial requests unlimited, parallel may 429. Responses carry `ETag`. `Access-Control-Allow-Origin: *` confirmed by hand, so browser fetch works. |
